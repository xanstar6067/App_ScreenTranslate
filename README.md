# Lenslate

Ручной перевод экрана Android поверх игр и приложений. Kotlin + Jetpack Compose, Android 8–16 (API 26–36).

- Одна перемещаемая кнопка: перевод, очистка, удержание для настроек.
- MediaProjection и локальный OCR: английский, японский, корейский, смешанный экран.
- Восстановление абзацев, определение языка, контрастные переводы поверх исходных областей.
- Google / Yandex Web, автоматический fallback, отмена и частичные результаты.
- SQLite-кэш и сохранение настроек; положение кнопки отдельно для двух ориентаций.
- Изображение не сохраняется и не отправляется в сеть. Передаётся только распознанный текст.
- Собственная адаптивная векторная иконка.

## Сборка

Открыть корень проекта в Android Studio и дождаться Gradle Sync. Требуются Android SDK 36 и JVM 25, заданная в Gradle daemon criteria.

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug --console=plain
```

Результат: `app/build/outputs/apk/debug/app-debug.apk`.

## Использование

1. Включить экранный переводчик, выдать overlay-разрешение и согласие на захват всего экрана.
2. Открыть нужное приложение и коротко нажать плавающую кнопку.
3. Повторное нажатие очищает переводы. Удержание открывает настройки.
4. Выключить сервис в приложении или через действие уведомления.

OCR-модели встроены. Для нового перевода нужна сеть; ранее сохранённые переводы доступны из локального кэша. Захват защищённого содержимого не обходится.
